# UnderAnime Rebirth TV - Releases

Repositorio publico de distribucion de **UnderAnime Rebirth TV**.

Aqui se publican exclusivamente:

- APKs firmados para Android TV y Fire TV.
- El archivo `version.json` consumido por el actualizador de la aplicacion.
- Notas de cada version.

El codigo fuente se mantiene en un repositorio privado independiente. El APK estable de cada release se publica con el nombre `underanime-tv.apk` mediante el flujo automatizado del proyecto.

`version.json` aparecera con la primera release firmada. No se publica una compilacion debug como actualizacion estable.
